# Арт-дирекция BMSTUDvach: «Редакционный архив»

## Визуальный аудит текущей системы

**Что есть сейчас:**
- Тёмная кибер-палитра: `bg-deep` oklch(0.10) — почти чёрный с синим оттенком
- Неоновый акцент: amber oklch(0.72 0.16 65) с glow-эффектами
- Моно-шрифт как дисплей: JetBrains Mono для заголовков
- CRT-эффекты, vignette, flicker
- Uppercase micro-labels с letter-spacing
- Glow-тени, неоновые hover-эффекты
- Общая эстетика: киберпанк/техно-сеть

**Проблемы:**
- Шаблонный AI/SaaS/cyberpunk вид (не уникальный)
- Моно-шрифт для заголовков — нет иерархии, нет редакционности
- Неоновые эффекты утомляют, не подходят для чтения
- Нет типографической культуры (заголовки = body по весу)
- Не подходит для long-form чтения (платиновые истории)

## Новая концепция: «Редакционный архив»

**Метафора:** BMSTUDvach — не кибер-сеть и не SaaS-дашборд. Это живой студенческий архив: смесь научного журнала, кампусной газеты и технического альманаха. Как у изысканного академического издания — типографика как главный герой, тёплая бумага как фон, один сдержанный акцент.

**Референсы (Awwwards 2024-2026):**
- Terminal Industries (SOTY 2025): тёплые нейтралы, типографика, щедрое пространство
- Siena Film Foundation (SOTM 2025): редакционная типографика, serif + sans
- Cartier Watches & Wonders (SOTM 2025): restrained palette, editorial layout
- Kellerstöckl: editorial typography, justified text

**Ключевые принципы:**
1. **Тёплая палитра бумаги** — кремовый/слоновая кость фон, глубокие чернила текст
2. **Типографика — звезда** — serif-дисплей для заголовков, sans для тела, mono только для данных
3. **Сдержанность** — один акцент, никаких glow и неоновых эффектов
4. **Щедрое пространство** — широкие поля, воздух вокруг элементов
5. **Асимметрия** — редакционные сетки, pull-цитаты, иерархия через масштаб
6. **Без uppercase+letter-spacing** — это киберпанк, уходим от этого

```css

--ink-secondary: #5B5547;      /* вторичный текст */

```

### Границы и акценты
```css
--rule: #D4CEB8;               /* hairline-бордеры, почти невидимо */
--accent: #2F4F4E;             /* глубокий приглушённый teal */
```

**Почему teal?** Необычно для imageboard (обычно bright red/blue), технический (как старые осциллографы/приборы), сдержанный, не кричит. Отличает от типичных red/orange accent'ов.

## Типографика

### Шрифты
- **Display (заголовки):** Cormorant Garamond — редакционный serif, есть кириллица, утончённый, variable font
  - `@fontsource/cormorant-garamond` (npm)
  - Weights: 400 (regular), 500 (medium), 600 (semibold), 700 (bold)
- **Body (основной текст):** Inter (уже есть) — 400, 500, 600, 700
- **Mono (данные, коды):** JetBrains Mono (уже есть) — только для технических элементов (номера постов, коды, данные)

### Type scale
```css
/* Базовый размер */
--text-base: 1rem;             /* 16px */
--text-sm: 0.875rem;           /* 14px */
--text-lg: 1.125rem;           /* 18px */

/* Заголовки (clamp для fluid typography) */
--text-h1: clamp(2.5rem, 5vw, 4rem);   /* 40-64px */
--text-h2: clamp(2rem, 4vw, 3rem);     /* 32-48px */
--text-h3: clamp(1.5rem, 3vw, 2rem);   /* 24-32px */
--text-h4: 1.25rem;                     /* 20px */
```

### Line-height
```css
--leading-tight: 1.3;          /* заголовки, компактный текст */
--leading-normal: 1.6;         /* body text */
--leading-loose: 1.8;          /* long-form reading */
```

### Правила
- Заголовки: `font-family: var(--font-display)` (Cormorant Garamond), `font-weight: 600`, `line-height: 1.3`
- Body: `font-family: var(--font-body)` (Inter), `font-weight: 400`, `line-height: 1.6`
- Mono: `font-family: var(--font-mono)` (JetBrains Mono) — только для: номера постов, коды, технические данные
- **НЕТ uppercase для micro-labels** — если нужен small text, используем `font-size: 0.875rem` без uppercase/letter-spacing
- **НЕТ mono для заголовков** — заголовки только serif

## Motion

### Timing
```css
--duration-fast: 150ms;
--duration-normal: 200ms;      /* было 300ms, теперь быстрее */
--duration-slow: 280ms;        /* было 500ms, теперь быстрее */
```

### Easing
```css
--ease-out: var(--ease-standard);  /* мост к ролям; никаких bounce */
```

### Принципы
- Motion = "бумага смещается", не "UI прыгает"
- НЕТ bounce, НЕТ spring, НЕТ neon flicker
- Hover: subtle background shift (paper-sunken), НЕ glow
- Focus: 2px solid var(--accent), outline-offset: 2px
- Selection: var(--accent) background, var(--paper) color

> Полный словарь движения — роли, кривые, материальные реакции, кинетика,
> magnetic, освещение, состояния и shader-акценты — в разделе «Motion system».

## 3D сцена

3D сцена (NetworkCanvas) читает CSS-переменные. При смене `--accent` цвета частиц/линий обновятся автоматически. Однако:
- Тёмно-синий фон 3D (`bg-deep`) не подходит к тёплой бумаге
- **Решение для этого раунда:** фокус на 2D дизайн-систему. 3D сцена останется как есть, но может выглядеть несоответствующе. Адаптация 3D — отдельная задача.
- Альтернатива: сделать 3D опциональным (по умолчанию off), фокус на типографику и 2D.

> Обновление: адаптация 3D под тёплую бумагу сделана для архива платинума —
> см. раздел «Archive Space». Сеть (`NetworkCanvas`) осталась как была.

## Archive Space

**Метафора:** `/platinum/` — это не «список под общим фоном», а физическое
хранилище. Кольца-эпохи, бумажные фрагменты-пластинки (по одной на
историю), янтарное ядро-хранилище в центре и пыль в луче света. Читатель
ищет историю — и она лежит на полке, а не прячется в прокрутке.

### Что читается как что

- **Кольцо — эпоха.** Год публикации (`published_at`) выбирает кольцо:
  истории одного года стоят на одном кольце, чем свежее эпоха — тем дальше
  от центра. История без даты публикации лежит на внутреннем кольце
  («неопубликованные»).
- **Фрагмент — история.** Одна пластинка на историю. Пластинка наклонена по
  типу источника — так видно, откуда пришла история, не читая её.
- **Ядро — хранилище.** Тёплое янтарное ядро в центре, вокруг которого
  вращается архив. Когда историй нет, ядро подсвечивает само себя.
- **Пыль — свет.** Медленная пыль в объёме колец даёт глубину и показывает,
  что пространство живое; в фокусе пыль уходит в тёплый тон.

### Раскладка: правила, а не случайность

Правила раскладки живут в `frontend/src/three/archive/layout.ts` — чистые
числа, без three.js и Vue, поэтому их можно тестировать без WebGL. Правило
одно: **один и тот же набор историй всегда даёт один и тот же архив**, а
порядок загрузки не влияет ни на что.

- **Кольцо** — по году публикации; история без даты → внутреннее кольцо.
  Радиус = `3.0 + 1.8 × tier` (3.0 / 4.8 / 6.6) либо явный список радиусов в
  опциях.
- **Угол** — золотой угол (2.39996 рад) × номер слота в кольце + разброс
  ±0.35 рад из хеша `id`: кольцо не выглядит расчёской.
- **Высота** — ±0.35 вокруг плоскости кольца, тоже из хеша.
- **Наклон** — по типу источника (`source_type`): generated `0.22`, dvach
  `−0.16`, custom `0.1`, imported `−0.24`, manual `0.16`; неизвестный тип →
  пластинка стоит прямо.
- **Масштаб** — `0.8…1.35` из хеша.
- **Хеш** — `hashId`, та же схема, что у сети: «случайно, но стабильно».
- **Кап** — 60 фрагментов (`DEFAULT_MAX_FRAGMENTS`); лишние отбрасываются
  стабильно по `id`, а сами истории остаются в списке.
- **Когда считать** — при смене набора историй, никогда в кадре.

Расширяя раскладку, держись этих правил: новые параметры — из хеша `id`
(иначе архив «прыгает» между загрузками), новые кольца — по смысловому
признаку (год, статус), и всё, что добавляет пластины, обязано укладываться
в кап.

### Палитра и материалы

Материалы архива процедурные: **ни одной текстуры**, только шейдеры на
`gl_FragColor` (совместимые с WebGL1). Палитра — из раздела «Палитра»:

| Смысл | Цвет | Где |
|---|---|---|
| Бумага | `#F2EDE0` | пластинка-фрагмент |
| Акцент | `#2F4F4E` | кромка фрагмента в фокусе |
| Янтарь | `#d4882a` | кольцо в фокусе, пульс ядра |
| Янтарь светлее | `#ffa840` | внутренний пульс ядра |
| Сталь | `#5a6480` | орбита в покое |
| Сталь светлее | `#8a94b8` | пыль |

- **Фрагмент** — тёплая бумага с зерном (хеш-шум: 3 октавы в `high`, 1 в
  `low`), и **свет только по кромке**: fresnel подсвечивает край пластинки,
  тело остаётся бумагой.
- **Акцент приходит только на кромку и только в фокусе** (`uFocus`): фокус —
  это подсветка ребра, а не заливка и не свечение.
- **Кольцо** — стальная линия с «дыханием» и бегущим шумом; в фокусе уходит
  в янтарь.
- **Ядро** — дрейфующая fresnel-кромка поверх янтарного пульса; при
  рассеивании сцены (`uDim < 0.5`) исчезает совсем.
- **Пыль и гало** — только additive и только медленные: пыль мерцает
  индивидуальной фазой (`aSeed`), гало горит, когда историй нет.
- **Единый контракт униформ** `uTime` / `uFocus` / `uDim` — общие по ссылке
  во всех материалах: сцена управляет всем архивом из одной точки.

**Правило «один accent на взаимодействие».** Фокус в архиве один: `uFocus` —
глобальная величина, поэтому в кадре может гореть только один фрагмент.
Второй акцент, второй подсвеченный объект, «радуга» статусов — не регистр
этого проекта. Янтарь — это тепло и пульс ядра, а не второй акцент.

### Правила движения

- **Камера летит ТОЛЬКО при открытии истории.** Наведение на фрагмент и
  перемещение по списку с клавиатуры только фокусируют — камера не прыгает за
  курсором. Перелёт (`archive-open` → `travelToFocus`) — 650 мс,
  ease-in-out: камера встаёт на 2.6 наружу от пластинки по радиусу и на 0.6
  выше, смотрит на саму пластинку и следует за её дрейфом.
- **Фокус ≠ перемещение.** Выбор фрагмента меняет свет, а не позу камеры.
- **Без фокуса — только дыхание.** Медленный обход архива (0.05 рад/с, радиус
  12.5, высота 2.2, вертикальная качалка ±0.5), вращение колец, дрейф
  пластин, мерцание пыли. Никаких автоперелётов, вспышек и миганий.
- **Перетаскивание** — ручной обзор: азимут 0.005 рад/px, высота 0.01 ед/px
  в пределах `[−1.5, 6]`; идущий перелёт имеет приоритет над drag'ом.
- **Reduced-motion = мгновенный финальный кадр.** Перелёт занимает один кадр,
  обход, дрейф, вращение и дыхание выключены; при этом униформы, рассеивание
  сцены и наведение указателя продолжают работать — читаемость не должна
  зависеть от анимации.

### Доступность

- **Список — источник правды.** DOM-список фрагментов — единственное, что
  читает скринридер; 3D — декоративный слой, который следует за списком, а
  не ведёт его.
- **Клавиатура.** `↑`/`↓` — соседняя строка, `Home`/`End` — края списка,
  `Enter` — открыть историю. Переносится настоящий DOM-фокус, фокус-ловушек
  нет, `Tab` не перехватывается.
- **Live-region.** `aria-live="polite"` объявляет «Фрагмент N из M · <title>»
  только при смене выделения; наведение мышью архив не тревожит.
- **Переключатель «3D / только текст».** `aria-pressed`, выбор помнится в
  `localStorage` (`bmstudvach-archive-3d`), по умолчанию — 3D. В текстовом
  режиме канвас не монтируется вовсе и WebGL-контекст освобождается.
- **Канвас** — `aria-hidden="true"`; у обёртки `role="img"` и подпись
  «Архивное пространство: кольца эпох и фрагменты историй».
- **Контраст подписей** — не ниже 4.5:1: для подписей приборной панели
  введён локальный токен `--archive-caption: #655E52` (5.5:1 на бумаге, 5:1
  на приподнятой бумаге).
- **320px.** 3D — фоновый слой, клики достаются списку (`pointer-events`
  только у самого канваса), а переключатель вообще убирает 3D, если места
  мало.

### Производительность

- **Бюджет контекстов жёсткий.** `MAX_ACTIVE_CONTEXTS = 2`
  (`src/composables/useThreeScene.ts`): сеть + warp. На маршруте платинума
  архив **занимает слот сети** (`AmbientField.vue` переключает слой по
  `mode === 'platinum'`), третий контекст не поднимаем.
- **Бюджет фрагментов** — 60 пластин (`DEFAULT_MAX_FRAGMENTS`); истории
  сверх капа остаются в списке, а не исчезают.
- **Переиспользование вместо пересоздания.** Все пластины делят одну
  `PlaneGeometry` и один материал; геометрия кольца кэшируется по радиусу,
  материал — по индексу кольца; сами меши берутся из пула, так что пересборка
  набора не создаёт ни одного three-объекта.
- **Кадр ничего не аллоцирует.** Raycast — не чаще раза в 3 кадра (или сразу
  при движении указателя), наведение подтверждается двумя проверками подряд.
- **Тир `low` — та же композиция, дешевле:** кольцо 96×6 → 40×4 сегментов,
  пыль 200 → 60 мошек, сфера гало 20×20 → 12×12, октавы шума 3 → 1 (тонкий
  слой зерна не считается вовсе). Текстур нет ни в одном тире.
- **Освобождение ресурсов.** Каждая геометрия и каждый материал отдаются
  ровно один раз, `dispose()` идемпотентен.

### Как добавить новую реакцию

1. **Реакция = событие + состояние.** Новый вариант события добавляется в
   конец union `SceneEvent` (`src/three/sceneState.ts`); существующие
   варианты не переименовываются и не удаляются — их читает весь проект.
2. **Источник правды остаётся списком.** Если реакция меняет то, что видит
   читатель, она живёт во вью; 3D только следует. Исключение — открытие
   истории: там первым говорит 3D (`archive-open`), и вью переходит по
   маршруту.
3. **Материал читает общий контракт.** Новый эффект берёт
   `uTime`/`uFocus`/`uDim` и палитру (бумага/ink/акцент/янтарь). Второй
   акцент в кадре или новый цвет — это уже другой язык.
4. **Движение — «дыхание», а не «прыжок».** Любая новая анимация обязана
   иметь мгновенный финальный кадр при `prefers-reduced-motion` и не двигать
   камеру сама: камера летит только на открытие.

## Motion system

**Философия.** Движение здесь — это реакция материала, а не украшение.
Бумага отзывается на свет, впитывает чернила под пальцем, слегка
приподнимается за уголок; она не «прыгает». Hover — это свет и кромка, а не
масштаб: увеличенный элемент выглядел бы плиткой в мобильном приложении, а
не листом, который подняли. Один акцент на взаимодействие: в кадре —
максимум один акцентный (`--accent`) и максимум один янтарный отклик.
Тишина важнее эффекта: если анимация не читается как «бумага, чернила,
свет» — её убирают.

**Где живёт.** Роли и кривые — `frontend/src/assets/motion.css`; материальный
слой поверхностей — `frontend/src/assets/material.css`; примитивы —
`frontend/src/composables/useMotion.ts`; кинетическая типографика —
`frontend/src/components/ui/KineticText.vue`; guard —
`frontend/scripts/verify-motion.mjs` (`npm run verify:motion`).

### Роли и кривые

Роль отвечает на вопрос «зачем это движение», а не «насколько оно длинное».
Имя выбирается по смыслу сцены, поэтому
`hover ≠ press ≠ reveal ≠ kinetic ≠ magnetic ≠ cinematic`. Роль — это пара
«время + кривая».

| Роль | Длительность | Кривая | Что означает |
|---|---|---|---|
| `--motion-hover` | 150ms | `--ease-standard` | отклик на курсор: бумага наклоняется к свету |
| `--motion-press` | 120ms | `--ease-entrance` | палец вдавливает лист: палец уже на месте |
| `--motion-reveal` | 600ms | `--ease-entrance` | контент выходит на страницу — медленно, чтобы его успели прочесть |
| `--motion-kinetic` | 28ms | `--ease-emphasized` | шаг между словами: ритм задаёт шаг, а не время |
| `--motion-magnetic` | 480ms | `--ease-emphasized` | элемент тянется к курсору: медленно и с весом |
| `--motion-cinematic` | 900ms | `--ease-entrance` | смена сцен и миров — единственное место, где время можно тратить щедро |

Кривая описывает **характер** движения, а не его длину — поэтому кривых
шесть, и у каждой своё лицо:

| Кривая | Значение | Характер |
|---|---|---|
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | основная динамика интерфейса: быстрый старт, мягкая остановка |
| `--ease-emphasized` | `cubic-bezier(0.33, 1, 0.68, 1)` | акцент, который должен быть заметен: чернильный след, отклик |
| `--ease-entrance` | `cubic-bezier(0.16, 1, 0.3, 1)` | вход из-за края или маски: долгий разгон, уверенный финал |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | уход элемента: быстрое начало, долгое затухание |
| `--ease-linear` | `linear` | ровный ход без ускорения: кольцо не дёргается на стыке цикла |
| `--ease-soft` | `ease-in-out` | спокойное дыхание прибора |

**Мост к старым местам.** `--ease-out` → `standard`, `--ease-out-quart` →
`emphasized`, `--ease-out-expo` → `entrance`: раньше все три кривые были
одинаковыми и различались только именем, теперь у каждой свой смысл, а
сотни мест, которые на них ссылаются, продолжают работать.

**Ритмы сцены** живут отдельно от ролей: `--motion-archive-orbit-slow/mid/fast`
(38s / 27s / 18s), `--motion-archive-pulse` (1.2s), `--motion-idle-pulse`
(2.4s), `--motion-tilt-duration` / `--motion-tilt-ease`. Период бесконечного
цикла не выражается ролью: у дыхания прибора нет ни «появления», ни
«наведения» — ни одна роль не передаёт его период.

### Материальный слой

`material.css` — единый язык реакций поверхностей. Поверхность здесь — это
бумага: она не растёт и не прыгает, она отзывается на свет, темнеет под
пальцем и впитывает чернила.

- **`.surface-paper`** — бумага: мягкая тень `--material-shadow-1`, волосяная
  кромка `--material-edge`, прямые углы (`border-radius: 0`).
- **`.react-lift`** — наведение и фокус: тень растёт до `--material-shadow-2`,
  кромка светлеет (`--material-edge-lit`). Геометрия не меняется.
- **`.react-lift--quiet`** — то же для крупных поверхностей (панели, строки
  длинных списков): анимируется только кромка, тень остаётся на месте — её
  пересчёт перерисовывает всю панель каждый кадр.
- **`.react-press`** — нажатие: тень сжимается в `--material-shadow-press`,
  кромка темнеет (`--material-edge-pressed`), лист уходит на
  `--material-press-delta` (1px).
- **`.react-press--flat`** — то же для крупных поверхностей: сдвиг и кромка,
  тень меняется мгновенно.
- **`.react-edge`** — свет по кромке со стороны курсора: слой-псевдоэлемент с
  `radial-gradient` по `--mx` / `--my`, проявляется через `opacity`. Свет лежит
  под текстом, но над бумагой, и **не перерисовывает** саму поверхность.
- **`.react-ink`** — чернильный акцент: тонкая линия проявляется от левого
  края, как след пера. Масштабируется **линия**, а не блок.

**Почему масштабирование запрещено.** `transform: scale()` меняет размер
блока, а значит — вёрстку вокруг него: карточка, которая на секунду стала
больше, разъезжается с соседями и выпадает из редакционной сетки. Материал
выражается кромкой, тенью и сдвигом на 1px — тем, что не меняет геометрию
страницы. Guard `verify:motion` запрещает `transform: scale()` в
`:hover`-правилах: это не договорённость, а красная проверка.

Базовые классы `motion.css`: `.motion-press` (вмятина), `.motion-press--flat`
(крупная поверхность), `.motion-reveal` (появление без FOUC), `.motion-quiet`
(только цвет и кромка — для вторичных ссылок и длинных списков).

### Кинетическая типографика

`KineticText.vue` — текст выезжает из-под **бумажной маски**
(`overflow: hidden` + сдвиг), а не проявляется и не вспыхивает. Это маска,
а не эффект: строка выходит из-за края, как лист, который поднимают над
обрезом. Режимы: `lines` (по переносам) и `words` (по словам); props —
`text`, `mode`, `delay`, `stagger`, `ease`, `as`, `duration`.

**Где ДОПУСТИМА.** Hero-кикер и заголовок секции — то, что человек читает
первым и что не обязано быть абзацем. Сейчас занято ровно одно место:
кикер hero на главной (`HomeView.vue`, `mode="words"`). Закон допускает
максимум три места в приложении.

**Где ЗАПРЕЩЕНА.** Списки, длинные тексты, тело постов, подписи в кнопках,
ячейки таблиц. Разбитый на куски текст перестаёт быть абзацем: его нельзя
прочесть, а прочесть здесь важнее, чем показать.

**Доступность.** Контейнер несёт `aria-label` с полным текстом, куски
помечены `aria-hidden` — скринридер читает текст ровно один раз. Для тегов,
чья роль не умеет носить имя (`<p>`, `<span>`), добавляется одна скрытая
копия: иначе строка молча выпала бы из accessibility-дерева.

### Magnetic

`useMagnetic(el, { strength, radius })` — элемент слегка тянется к курсору.
Смещение в пикселях пишется в `--mag-x` / `--mag-y` и применяется отдельным
CSS-свойством `translate`, чтобы не затирать наклон `useTilt`.

**Живёт ровно в одном месте приложения:** главная кнопка запуска
(`components/launch/LaunchBay.vue`, `strength: 8`, `radius: 120`).

**Почему ровно в одном месте.** Тяга — это внимание, а внимания должно быть
мало. Кап объявлен дважды, чтобы система не разошлась сама с собой:
`--motion-cap-magnetic: 1` в `motion.css` и `MAGNETIC_CAP = 1` в
`useMotion.ts`. Второй претендент остаётся статичным.

**Как выключается.**
- Системная настройка «меньше движения», тач-устройство или выключенное
  качество 3D (`motionAllowed()`) — примитив не подписывается вовсе: 0
  слушателей, 0 следов в DOM.
- Клавиатура ведёт (любая клавиша, кроме модификаторов) или элемент в фокусе
  — тяга отпускается сразу, а не долетает по инерции.
- Указатель ушёл из окна (`pointercancel` / `blur`) — элемент возвращается на
  место.
- Смещение ограничено краем окна — на 320px и при зуме 200% горизонтальная
  прокрутка не появляется.

### Реактивное освещение

`usePointerLight(el, { radius })` пишет в элемент `--mx` / `--my` —
координаты курсора в процентах от левого верхнего угла (50% / 50% — центр) —
и `--m-light-radius`. CSS рисует по ним пятно света в `.react-edge::before`.

**Что это даёт.** Бумага ловит свет со стороны курсора: кромка теплеет,
плоскость остаётся плоскостью. Это не подсветка и не неон.

**Бюджет.** `--motion-cap: 2` (CSS) и `LIGHT_CAP = 2` (код) — свет живёт
максимум на двух поверхностях страницы. Носителей в приложении три: кнопка
героя на главной (радиус 120), рамка линзы поиска (260) и кольцо выбранной
причины жалобы (90) — но они не живут одновременно, а кап защищает от
будущих поверхностей.

**Правило.** Свет — только на «герой»-поверхностях. На каждой карточке он
превратился бы в коллекцию прожекторов.

### Состояния

Единый язык прибора. `LoadingState`, `ErrorState`, `EmptyState` и
`NotFoundState` (404 / «показаний нет» / «доступ закрыт») собраны на одном
словаре: рамка с уголками в акценте состояния, моно-подпись, приборная
графика, строка сообщения гарнитурой корпуса и зарезервированная высота
(`232px` на рамке, `44px` на строке действия, `3rem` на сообщении) — контент
не прыгает при смене состояния.

**Чем различаются.**

- **loading** (`SCANNING…`) — сканирующий луч и накопление сигнала; акцент
  `--accent`; `role="status"`, `aria-busy="true"`.
- **error** (`ERROR`) — линия разорвана; акцент `--danger`; `role="alert"`;
  действие «Повторить».
- **empty** (`EMPTY NODE`) — ровная линия без сигнала; приглушённый акцент;
  место для действия.
- **404** (`FRAGMENT LOST`) — след вырезанного фрагмента. Родственники:
  `NO READINGS` (показаний нет) и `ACCESS SEALED` (доступ закрыт) — статичная
  графика, без анимации.
- **оффлайн** — `OfflineBadge`: бумажная плашка с волосяной рамкой,
  моно-подпись, чернильный квадрат-метка. Без мигания.

Один акцент на состояние: loading — accent, error — danger, empty —
приглушённый accent. Неона и «красной стены» нет. Контраст посчитан
по-настоящему: подписи состояний 5.84–7.04:1 к бумаге, кромка действия
(`--state-border`, 65% акцента) — 3.24–3.65:1.

**3D-сцена говорит тем же языком.** Фазы архива — `loading | ready | error |
empty` (`ArchiveSpacePhase`). Ожидание: кольца просыпаются по очереди.
Сбой: часы шейдеров останавливаются, свет уходит, пыль оседает — **сбой
это остановка часов, а не мигание**. Тишина: медленный дрейф без пыли. Под
reduced-motion состояние применяется сразу, одним кадром.

### Shader-акценты

3D в проекте не «светится» — он материален. Все акценты процедурные, на
`gl_FragColor`, без текстур:

- **«Бумажный просвет»** (`three/archive/materials.ts`) — мягкий
  subsurface-lite: спад по нормали и медленно ползущее пятно света, цвет —
  смесь бумаги и янтаря, **без emissive**. На тире `low` выключается целиком:
  картинка честно проще, а не сломана.
- **Янтарная кромка** — `uEdgeColor` (`#d4882a`) загорается только в фокусе;
  в покое пластина оставляет на кромке шёпот акцента — «напечатанный край
  страницы».
- **Accent sweep** (`three/network.ts`) — одна медленная полоса тёплого
  света, идущая по узлу (период ~9 с, амплитуда ≤ 0.26). Фаза у каждого узла
  своя: узлы не блестят хором.
- **«Чернильное» зерно** (`network.ts`, `warps.ts`) — мизерная неоднородность
  (≤ 8 % яркости в сети, ±3 % по цвету в вуале), чтобы плоскость не была
  мёртвой; зерно приклеено к поверхности и вращается вместе с узлом.
- **Тепло у курсора** (`network.ts`) — узел рядом с курсором смещается к
  янтарю на 32 % (кромка — на 40 %) и плавно гаснет, когда указатель уходит.
  Это тепло, а не неон.

**Запрещено:** неон, glow-тени, CRT-эффекты (CRT в проекте есть, но он
opt-in и по умолчанию выключен).

### Бюджет внимания и производительность

- **Внимание.** Свет по кромке — максимум две поверхности
  (`--motion-cap: 2`), магнит — одна (`--motion-cap-magnetic: 1`),
  кинетическая типографика — максимум три места в приложении (фактически
  одно).
- **Что анимируется.** В анимации живут только compositor-свойства:
  `transform`, `opacity`, `color`, `border-color`. `box-shadow` перерисовывает
  поверхность целиком — поэтому он анимируется только на мелких поверхностях
  (кнопка, плашка, карточка), где тень единственный способ выразить
  материал. Крупные поверхности берут `.react-lift--quiet`,
  `.react-press--flat`, `.motion-press--flat`.
- **Длинные списки — без per-row трансформаций.** Ни одна строка списка не
  сдвигается и не растёт: реакция ограничена цветом и кромкой, а появление —
  прозрачностью.
- **`will-change` — только на время движения.** В `motion.css` и
  `material.css` постоянных промоушенов нет: `useMagnetic` навешивает
  `will-change: translate` на время смещения и снимает его в покое. В
  карточках с наклоном (`BoardCard3D`, `DepthCard`) и в кольцах пустого
  архива `will-change: transform` объявлен в постоянном правиле и снимается
  (`will-change: auto`) под reduced-motion.
- **Слушатели и кадры.** `usePointerLight` — один слушатель `pointermove` и
  разовый кадр (без цикла); `useMagnetic` — три window-слушателя и один
  rAF-цикл, который останавливается, как только элемент пришёл к цели;
  `usePress` — семь слушателей и ноль кадров. Тяжёлых rAF-циклов на странице
  не больше одного.
- **Запись в стиль — только при заметном изменении:** порог 0.5 % для света,
  округлённое значение — для тяги.
- **Отключение.** Движение выключается при системном «меньше движения», на
  тач-устройствах и при выключенном качестве 3D (`quality: 'off'`). Реакция
  приходит на лету: подписки снимаются, следы в DOM исчезают.
- **`transition: all` запрещён** — «мусорка» анимирует свойства, которых не
  просили, и ломает те, которые просили.

### Reduced-motion

**Правило: сначала финальный кадр, потом анимация.**

- Стартовое состояние (`opacity: 0`) живёт только внутри
  `@media (prefers-reduced-motion: no-preference)`. В DOM нет ни одного
  `opacity: 0` для контента: текст виден всегда, даже если анимация не
  запустилась.
- `KineticText` при выключенном движении не трогает DOM вовсе — `gsap.fromTo`
  не вызывается, текст остаётся обычным.
- `motion.css` и `material.css` объявляют явную ветку `reduce` для каждой
  реакции: тени и кромки меняются мгновенно (это состояния), лист не едет под
  пальцем, свет по кромке не перетекает, появление — сразу финальным кадром.
- `usePointerLight` и `useMagnetic` при выключенном движении не подписываются
  вообще: ни слушателей, ни инлайн-стилей.
- `usePress` продолжает работать: нажатие — это состояние («чернила
  впитались»), а не движение.
- Никакого FOUC: до запуска анимации в DOM лежит финальный кадр.

### Как добавить новую реакцию

1. **Определить роль.** Спроси «зачем это движение» — наведение, нажатие,
   появление, кинетика, магнит, кинематограф — и возьми соответствующую роль
   из `motion.css`. Если роли нет, а место есть, сначала поговори об этом, а
   не заводи шестую кривую «на глаз».
2. **Не изобретать тайминг.** Длительность и кривая — только токены
   (`--motion-hover`, `--ease-standard` и т. д.). Своё число — только если
   это новый ритм прибора, и тогда оно живёт в `motion.css` ровно один раз.
3. **Выбрать материал, а не эффект.** Реакция — это тень, кромка, цвет или
   сдвиг на 1px. Масштабирование запрещено, `transition: all` запрещён.
4. **Учесть поверхность.** Мелкая (кнопка, плашка, карточка) — можно
   анимировать тень. Крупная (панель, строка списка) — только кромка, а в
   длинных списках — только opacity.
5. **Дать статичный эквивалент.** Элемент обязан иметь финальный кадр: без
   `opacity: 0` вне `no-preference`, с мгновенным состоянием при
   reduced-motion.
6. **Не сломать бюджет и guard.** Свет — не больше двух поверхностей, магнит
   — один, кинетика — максимум три места. Если кап уже занят, поверхность
   остаётся статичной. `npm run verify:motion` обязан остаться зелёным: его
   реестр долга — список честных исключений с причиной, а не свалка.
