      (синус с индивидуальной фазой `uPhase`) + бегущий шум (прокручиваемое
      поле, сэмплится по фиксированной проекции локальной позиции — работает

    - `vaultMaterial(three, opts)` — ядро-хранилище: медленный «плывущий»
      fresnel + внутренний amber-пульс; при `uDim < 0.5` (`smoothstep(0.5, 1.0,
      uDim)`) уходит в почти невидимый.
    - `dustMaterial(three, opts)` — замена `PointsMaterial` на шейдере: additive,
      мерцание по `uTime` с индивидуальной фазой из атрибута `aSeed`

SUMMARY:
Модуль `src/three/archive/materials.ts` даёт сцене Archive Space пять процедурных
фабрик (`fragmentMaterial`, `ringMaterial`, `vaultMaterial`, `dustMaterial`,
`emptyHaloMaterial`) с единым контрактом униформ: `uTime`/`uFocus`/`uDim` — это
одни и те же объекты во всех материалах, поэтому сцена управляет всем архивом
из одного места через `archiveUniforms()`. Арт-дирекция соблюдена: фрагмент —
это тёплая бумажная пластинка с зерном и подсветкой акцентом строго по кромке,
кольца — тихие стальные линии с бегущим шумом (amber при фокусе), ядро —
медленный amber-пульс, пыль и гало — только additive и без вспышек. Обе
ветки качества компилируются как обычный GLSL ES 1.00: октавы запекаются в
исходник в JS вместо `#define`, поэтому и 'high', и 'low' читаются любым
проверяющим компилятором; тесты проверяют и контракт, и различие тиров, и
отсутствие утечек (`dispose`).

FOLLOWUPS:
- `uFocus` в `vaultMaterial` сейчас только усиливает кромку (`rim * (1 + focus *
  0.5)`); если в P2-T1 ядро должно «открываться» при выборе истории — стоит
  добавить отдельный импульс/раскрытие, а не переиспользовать общий `uFocus`
  (он же используется кольцами и пластинками).
- Общие по ссылке `uDim`/`uFocus` — осознанное решение («сцена двигает общие
  униформы одним place»), но это значит, что точечно приглушить один фрагмент
  нельзя. Если P2-T1/P4-T2 понадобится per-fragment затемнение, потребуется
  либо второй набор униформ (`uDimLocal`), либо раздельные банки по кольцам.
- `dustMaterial` требует атрибут `aSeed` на геометрии точек; сцена обязана
  добавить его (`BufferAttribute`) — иначе пыль мерцает синхронно (не падает,
  но выглядит мёртвой). Стоит зафиксировать это в `verify:3d` на P2-T5/P4-T3.
- Гало (`emptyHaloMaterial`) считает радиальный спад по `uv` — использовать
  его нужно на плоскости с uv (PlaneGeometry), иначе `uv` будет (0,0) и гало
  не отрисуется. Стоит упомянуть в P2-T1 (empty-режим).
- Шейдеры проверены только структурно (тесты на содержимое исходников и
  WebGL1-безопасность); реальной компиляции GLSL в headless-окружении нет
  (нет `headless-gl`/валидатора, новые зависимости запрещены). Первый
  визуальный прогон сцены в P2-T1 — самый честный тест шейдеров.
