SUMMARY:
1. `listDrafts()` обобщён (задача 1). Вместо `SIGNAL_DRAFT_KEY = /^signal-(\d+)$/` — диспетчер трёх форм ключей в `parseDraftKey()`: `signal-<threadId>` → `kind:'signal'` + `threadId`, `launch-<boardSlug>` → `kind:'launch'` + `boardSlug`, `report-<postId>` → `kind:'report'` + `postId`. `DraftSummary`: `kind` обязателен, `threadId?/boardSlug?/postId?` необязательные, добавлено `title?` (заголовок треда для launch / причина для report). Обратная совместимость: сигнальная запись — та же форма, что и раньше, плюс `kind`.
2. Честность subject'а: report-ключ знает только пост, поэтому `threadId` для жалоб не выдумывается — панель показывает строку без навигации (см. п.4). Слаг читается по символьному набору бэкенда (`[a-z0-9][a-z0-9_-]*`), но без минимальной длины бэкенда: composer мог сохранить буфер на коротком слаге (в приложении и тестах живёт `/b/`), а более строгий читатель, чем писатель, спрятал бы настоящий черновик. Первая версия regex была строже — тесты это сразу поймали (`draft:launch-b` не попадал в панель), исправлено + регресс-тест «reads a short board slug the way the composer wrote it».
3. Порог «это ещё черновик»: запись попадает в список, если есть текст, заголовок/причина или вложения. Для сигналов поведение не изменилось (title у них не пишется) — старые тесты прошли без правок логики.
4. DraftsPanel (задача 2). Строки рендерятся через `toRow(DraftSummary) → DraftRow` с честными подписями: «ответ в треде #7» (ссылка `/threads/7`), «новый тред /bauman/» (ссылка `/boards/bauman?launch=1`), «жалоба на пост #42» (без ссылки — только «удалить буфер»). Превью launch — `title || body`. Сортировка по `savedAt` desc сохранена; удаление — прежний `discardDraft(key)` по сырому ключу; стили панели, `drafts__refresh/preview/meta/files/time/resume/delete`, mobile 320px и `prefers-reduced-motion` блоки не тронуты (переименован только CSS-класс `.drafts__thread` → `.drafts__subject`, т.к. подпись перестала быть только номером треда). Заголовок панели: «НЕЗАКОНЧЕННЫЕ СИГНАЛЫ» → «ЧЕРНОВИКИ» (aria-label «Незаконченные черновики») — панель больше не только про ответы; ассерты в двух спеках обновлены.
