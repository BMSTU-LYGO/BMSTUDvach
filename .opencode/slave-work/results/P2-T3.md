SUMMARY:
Собран `ArchiveSpaceCanvas.vue` — тонкая Vue-обёртка над `useThreeScene` (по образцу `NetworkCanvas.vue`), подключающая самостоятельный Three.js Archive Space (`src/three/archive/space.ts`, публичный API сверен с диском и совпал с ожидаемым: `buildArchiveSpace(three, quality, opts)` → `ArchiveSpaceController` c `scene/camera/setStories/focus/travelToFocus/releaseFocus/setPointer/pointerStoryId/openStory/orbitBy/update/dispose`).

Сцена (build):
- `buildArchiveSpace(ctx.three, ctx.quality === 'high' ? 'high' : 'low')` — `three` приходит только из `ctx` (рантайм-импорта `three` в канвасе нет, только тип `typeof import('three')` в спеке);
- сразу `space.setStories(sceneState.archiveStories)`;
- подписка `onSceneEvent`: `archive-focus` → `focus(target)`; `archive-open` → `focus(target)` + `travelToFocus()`; `archive-clear` → `focus(null)` + `releaseFocus()`;
- watch по id-сигнатуре `sceneState.archiveStories.map(s => s.id).join('|')` → `setStories(...)` (identity-шум не пересобирает архив);
- watch `() => sceneState.focusedStory` → `space.focus(id)` — БЕЗ `travelToFocus()`: камера не прыгает за курсором при внешнем hover (travel только по клику/открытию, как и просили);
- `frame(dt)` → `space.update(dt, { stories, focusedStory, selectedStory, reducedMotion: prefersReducedMotion() })`;
- `dispose` снимает подписку событий, оба watch-stop, слушатели указателя и вызывает `space.dispose()`; teardown идемпотентен (вызывается и из `dispose`, и из `onUnmounted`).

Указатель (окно + бундер канваса, как в NetworkCanvas, но NDC относительно бунда):
- `pointermove` на `window` → NDC из `clientX/clientY` и `canvas.getBoundingClientRect()` (не окна — архив может быть не fullscreen) → `space.setPointer(x, y)`;
- затем hover: `hovered = space.pointerStoryId()`; если `hovered !== sceneState.focusedStory` → `focusStory(hovered)` + `emitSceneEvent({ type: 'archive-focus', target: hovered })`;
- если указатель над DOM-строкой списка (`closest('[data-testid="fragment-row"]')`) — фокус не трогаем вообще: строка сама владеет фокусом (контракт P3-T1);
- drag: `pointerdown` (только основная кнопка) → `setPointerCapture` (в try/catch), `pointermove` с зажатой кнопкой → `space.orbitBy(dx, dy)`, фокус при этом НЕ меняется; `pointerup`/`pointercancel` → отпускание и снятие захвата;
- клик ≠ drag: порог 4px, при превышении `archive-open` не эмитится (а следующий полноценный клик уже открывает);
- `click` на канвасе → `space.focus(id)` + `selectStory(id)` + `emitSceneEvent({ type: 'archive-open', target: id })` + `space.travelToFocus()` (кинематографичный подлёт перед переходом);
- `wheel` НЕ перехватывается вообще (слушателя нет) — страница скроллится; слушатели `passive`.

Шаблон/стили: `.archive-canvas-wrap` (absolute, inset 0, `overflow: hidden`, `z-index: 0`, `pointer-events: none` — фон, клики к DOM-списку проходят) c `<canvas class="archive-canvas" :class="{ hidden: !active }" aria-hidden="true">` (`pointer-events: auto` — только канвас) и fallback-блок `.archive-fallback` при `!active` (мягкий radial-gradient в регистре архива, `aria-hidden="true"`). Без `console.*`, без новых зависимостей.
