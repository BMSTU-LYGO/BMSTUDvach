SUMMARY:
Added `import { prefersReducedMotion } from '@/composables/useGsap'` and a single per-frame
`prefersReducedMotion()` read (`reducedMotion`) at the top of `update(dt)`. P6-T1: in home
mode (motion allowed, nothing hovered, no travel running) the camera auto-orbits —
`x = cos((orbitPhase + elapsed * 0.05) * 17)`, `z = sin(...) * 17`, y eased into a 0.5-amplitude
bob around `cameraPresets.home.y`, `lookAt(0,0,0)` — fully replacing the presence lerp; the
orbit phase is re-anchored whenever the orbit is entered (mount, travel end, hover release)
so it picks up exactly where the camera stands instead of snapping to a fixed point of the
circle. P6-T2: hover focus resolves the highlighted board node and biases the camera target
by `node.pos * 0.2` on x/y with `lookTarget` at `node.pos * 0.3` (between the core and the
node); it composes with the mode preset/parallax/breathing, outranks the auto-orbit so the two
never run together, and is skipped for the board the camera already frames. P6-T3: reduced
motion disables auto-orbit, hover focus and node spin (`rotation.y/x` untouched, so they stay
exactly 0), forces the ambient pulse interval to 10s, and keeps hover lighting on the hovered
node only (no NEIGHBOR_GLOW ripple to its inter-board links).

New constants: `PULSE_INTERVAL_REDUCED = 10.0`, `ORBIT_RADIUS = 17`, `ORBIT_SPEED = 0.05`,
`ORBIT_BOB_AMPLITUDE = 0.5`, `ORBIT_BOB_SPEED = 0.1`, `FOCUS_STRENGTH = 0.2`,
`FOCUS_LOOK_AT = 0.3`, plus `orbitPhase` / `wasOrbiting` state. Existing methods
(`setBoards`, `pulseAt`, `sendReply`, `rescue`, `travelTo`, `morphTo`,
`anchorSharedElement`, `launchEnvoyPacket`, `getNodeAtPointer`, …) are untouched.

BLOCKERS/FOLLOWUPS:
- Focus bias deliberately skips the board currently framed by `board` mode
  (`highlightedBoard === boardSlug`) to keep the existing board-mode camera composition intact.
- Focus is applied on top of the mode preset (as an offset on `tx`/`ty`) rather than replacing
  the lerp, per PLAN.md P6-T2 wording ("плавно смещается к узлу"); this keeps pointer parallax
  and breathing active during a hover and avoids a camera pop when the hover releases.
- Hover focus also applies in `thread` mode (3D raycast hover of a node) — subtle, not
  covered by the acceptance criteria, no regression observed.
- `orbitPhase` seeds at π/2 so the orbit starts at `cameraPresets.home` (0, 1.2, 17); all
  presets share x=0, so travel-end parking always re-anchors to π/2.
