SUMMARY:
Вью `/platinum/` стало двусторонним мостом между читаемым списком и 3D-пространством, при этом разметка, типографика, `data-testid` (`fragment-row`, `platinum-empty`) и структура `<ol class="fragments">` сохранены без изменений.

1) API → сцена. Добавлен `archiveRefs(list)` → `ArchiveStoryRef[]`: `{ id, title, year, ringIndex, sourceType }`. Год берётся из `published_at` (`yearOf`: `Date.parse` → `getFullYear()`, null при отсутствующей/нечитаемой дате). Кольца считаются один раз через `ringsFor()` из `@/three/archive/layout` (не хардкод): кольцо истории ищется по `ring.stories` → `ring.index`; неопубликованные (`published_at = null`) попадают в нулевое (внутреннее) кольцо, опубликованные — по возрастанию года (2025 → ringIndex 1, 2026 → ringIndex 2). `setArchiveStories(refs)` вызывается после `load()` и после каждого `loadMore()` — во втором случае по ВСЕМ загруженным историям (`stories.value`), т.е. пространство растёт вместе со списком. `setStoryCount(result.count)` оставлен как есть (его проверяют `verify:3d` и сетевой сценарий). При старте загрузки, при ошибке и при пустом результате — `setArchiveStories([])`: кольца «дышат вхолостую».

2) Список → 3D. На строке (`RouterLink.fragment-link`) навешены `@pointerenter`/`@mouseenter` → `focusStory(id)` + `emitSceneEvent({ type: 'archive-focus', target: id })`; `@pointerleave`/`@mouseleave`/`@blur` → `focusStory(null)` + `archive-focus: null`, но только если уходим с той же строки (`sceneState.focusedStory === id`) — более новый фокус не перетирается. Повторные enter/focus по той же строке не дают лишних emit'ов (guard по текущему `focusedStory`). `sounds.click()` не вызывается.

3) 3D → список. `watch(() => sceneState.focusedStory, ...)` (с `immediate: true`) ставит строке `data-focused="true"` и класс `.fragment-link--focused`, с прежней строки метка снимается (реактивная привязка, а не ручная правка DOM). Мягкий `scrollIntoView({ behavior: prefersReducedMotion() ? 'auto' : 'smooth', block: 'nearest' })` — только если строка реально вне видимой полосы списка (viewport, обрезанный самим контейнером) и `!prefersReducedMotion()`; `scrollIntoView` вызывается на самой строке, layout не выбивается (`block: 'nearest'`).

4) Клик по строке → `openRow(story.id)` → `selectStory(story.id)` перед уходом на страницу; `preventDefault` не вызывается, родной переход `RouterLink` сохраняется.

5) 3D → роутер. В `onMounted` подписан `onSceneEvent` (отписка в `onBeforeUnmount`): на `archive-open` — `selectStory(ev.target)` + `router.push('/platinum/' + ev.target)` (роутер получен через `useRouter()`). Событие `archive-focus` от канваса не дублируется — канвас сам пишет в `sceneState.focusedStory`, реагирует watch.

6) Стиль/доступность. Добавлен `.fragment-link--focused` (без `!important`): та же hairline-левая метка и фон, что у hover, transition в существующем регистре `--archive-duration`/`--ease-out-quart`; в `@media (prefers-reduced-motion: reduce)` его transition отключается. Никаких изменений measure/типографики/отступов чтения.

Тесты (новый блок «PlatinumView — the archive and the 3D space (P3-T1)», 11 кейсов): фиды сцены (year/ringIndex/sourceType для трёх эпох), `setStoryCount`/`storyCount`, рост набора при `loadMore`, hover → `focusedStory` + событие `archive-focus` до подписчика, mouseleave → сброс фокуса, «старый leave не перетирает новый фокус», `data-focused`/`.fragment-link--focused` по `sceneState.focusedStory`, мягкий scrollIntoView с `{ behavior: 'smooth', block: 'nearest' }`, клик → `selectedStory`, внешний `archive-open` → `router.push('/platinum/5')`, ошибка API → `archiveStories` пуст.
