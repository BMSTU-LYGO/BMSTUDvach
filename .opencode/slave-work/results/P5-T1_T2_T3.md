BLOCKERS/FOLLOWUPS:
- Ambient pulse uses the shared `pulseAt` ring pool (8 rings); with many boards several pulses can overlap briefly — acceptable now, but a per-node "ambient" ring variant (cheaper, no camera kick) would be cleaner if the constellation grows.
- `getNodeAtPointer` allocates a `map` over nodes per pointermove event (not per frame); negligible at current board counts, could be cached if profiling says otherwise.
- Raycast hit boxes are the node geometries (0.55 radius) — comfortable but not generous; a dedicated invisible `SphereGeometry` hit-proxy per node would give a bigger, more forgiving target.
