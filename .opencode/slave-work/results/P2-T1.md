SUMMARY:

1. `src/three/archive/space.ts` — билдер сцены архива без рантайм-зависимостей:
   - `type ThreeModule = typeof import('three')`, `three` передаётся снаружи; ни одного
     рантайм-импорта `three`/`vue`, ни одного `console.*`.
   - Экспортирует `ArchiveSpaceSnapshot` (`stories`, `focusedStory`, `selectedStory`,
     `reducedMotion`), `ArchiveSpaceController` (`scene`, `camera`, `setStories`, `update`,
     `dispose`), `ArchiveSpaceOptions` (`maxFragments`, `layout`) и
     `buildArchiveSpace(three, quality, opts?)`.
   - Камера — статичный риг: `PerspectiveCamera(50, 1, 0.1, 200)` на (0, 2.2, 12.5),
     `lookAt(0, 0, 0)`. Камеры/фокуса/указателя/raycast нет — это P2-T1b.
   - Всё живёт в одной группе `world` (`archive-space`), добавленной в `scene`.

2. Граф сцены:
   - **Кольца**: `ringsFor(stories)` → на кольцо `LineSegments` из
     `EdgesGeometry(TorusGeometry(radius, 0.035, 6, high ? 96 : 40))`, материал
     `ringMaterial(three, { quality, phase: index * 1.1 })`,
     `rotation.x = PI/2 + (index - 1) * 0.3`, `rotation.z = 0.12 * (index - 1)`,
     имя `archive-ring-<index>`. Радиусы колец берутся из раскладки (3.0 / 4.8 / 6.6 …).
   - **Фрагменты**: `placeFragments(stories, { maxFragments: opts.maxFragments ?? 60, ...opts.layout })`
     → `Mesh(PlaneGeometry(0.85, 1.1), fragmentMaterial(three, { quality }))` с
     `position.set(x, y, z)`, `rotation.set(0, angle, tilt)`, `scale.setScalar(placement.scale)`,
     `userData.storyId = placement.id`, имя `archive-fragment-<id>`. Геометрия и материал
     пластин — общие на весь архив (переиспользование, при пересборке не удаляются).
   - **Ядро**: `vault` — `LineSegments(EdgesGeometry(DodecahedronGeometry(1.1)), vaultMaterial(...))`;
     рядом аддитивная glow-сфера `Mesh(SphereGeometry(1.4, 20, 20), emptyHaloMaterial(...))`
     (`archive-halo`) — ссылки `haloMat`/`haloMesh` удерживаются для empty-режима.
   - **Пыль**: `Points(BufferGeometry, dustMaterial(...))`, 200 частиц (high) / 60 (low),
     атрибуты `position` (Float32BufferAttribute, 3) и `aSeed` (Float32BufferAttribute, 1)
     одинаковой длины; распределение по сферическому объёму радиуса 8, полностью
     детерминированное (хеш `hashId` из layout.ts, `Math.random` не используется).

3. `setStories(stories)`: маппит `ArchiveStoryRef` → `LayoutInputStory` (`id`, `sourceType`,
   `year`), пересобирает кольца и пластинки; старые кольца снимаются с `world` и их
   собственные геометрии/материалы освобождаются (общая `PlaneGeometry` пластин не трогается).
   Пустой набор → 3 «дежурных» кольца на радиусах 3.0/4.8/6.6 (empty-режим не пустует) и
   `haloMat.uniforms.uDim.value = 1`; иначе `uDim = 0`. У halo свой `uDim`-uniform, чтобы
   свечение пустого архива не зависело от presence-fade остальной сцены.

4. `update(dt, snap)`: `elapsed += dt` → `uTime`; presence-lerp `presence += (1 - presence) *
   min(1, dt * 2)` → `uDim`; `uFocus` = 0.9 при `snap.focusedStory != null`, иначе 0; множитель
   presence применяется к `world.scale` (масштаб пластин не переписывается); кольца медленно
   вращаются (`rotation.z += dt * spin`, знак по индексу); пластины дрейфуют по y
   (`sin(elapsed * 0.6 + angle * 3) * 0.35`); halo «дышит»
   (`scale.setScalar(1 + sin(elapsed * 0.9) * 0.04)`). Кадр O(фрагментов), без аллокаций
   (никаких Vector2/Vector3 в циклах). При `snap.reducedMotion` позиционная анимация
   выключается (uniforms и presence-fade остаются).

5. `dispose()`: `world` убирается из `scene`, кольца/пластины снимаются, все материалы
   освобождаются через `disposeArchiveMaterials([...])`, все геометрии (кольца/ядро/halo/
   пыль/общая плоскость пластин) — `dispose()`. Идемпотентно: повторный вызов безопасен,
   `update`/`setStories` после dispose — no-op.

6. Тесты (`src/three/archive/__tests__/space.spec.ts`, реальный `three`, как в
   network.spec.ts; `vi.spyOn(HTMLCanvasElement.prototype, 'getContext').mockReturnValue(null)`):
   14 кейсов — граф сцены (кольца/vault/dust), атрибуты пыли (`position` и `aSeed` одинаковой
   длины), позиция камеры, одна пластинка на историю с `userData.storyId`, 30 кадров `update`
   без исключений, общая геометрия/материал пластин, пересборка без накопления объектов,
   детерминизм позиций, empty-режим (голые кольца, halo `uDim > 0.5`, безопасный `update`),
   гашение halo при появлении историй, `dispose()` дергает `geometry.dispose`/`material.dispose`
   (шпионы на прототипах), идемпотентность `dispose()` и безопасный `update` после него,
   `world` убран из сцены.
