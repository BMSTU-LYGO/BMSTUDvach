SUMMARY:
1. Метаданные файлов (DRAFT-01): новый экспорт `MetaFile {name, size}`; `Draft.files` уточнён до `MetaFile[]` (было `File[]`). `saveDraft` принимает `DraftInput = string | {title?, body, files?: Array<MetaFile|File>}` — File-подобные объекты приводятся к `[{name,size}]` через `toMetaFiles()`, в localStorage попадает только сериализуемое. Загрузка: `draft.value.files` = метаданные из стораджа, не File-объекты. Старый формат (`files: []`) читается как есть.
2. Flush: payload дебаунса держится в `pending`; `pagehide` и `visibilitychange` (при `document.visibilityState === 'hidden'`) пишут его немедленно через `persist()` (idempotent — таймер после flush пишет второй раз повторно, т.к. pending обнуляется). Слушатели регистрируются в `onMounted`, снимаются в `onUnmounted`; на `onUnmounted` тоже делается flush (уход со страницы/роут не должен терять текст сильнее, чем закрытие вкладки).
3. Quota/security: `persist()` ловит исключение `localStorage.setItem`, ставит `status='error'` и логирует warn — исключение наружу не выбрасывается (и в дебаунсе, и во flush).
4. Честный restore: добавлен `hasRestoredFiles: boolean` — true, когда загруженный черновик имел метаданные вложений. При `clearDraft()` сбрасывается в false. Существующий контракт `{draft, hasDraft, status, savedAt, saveDraft, clearDraft, restoreDraft}` сохранён полностью — SignalDock/LaunchBay/ReportProbe компилируются и работают без единой правки.
5. listDrafts(): `filesCount` считается через `countMetaFiles(record.files)` — одинаково с тем, что реально восстановится; DraftsPanel не тронут, поведение прежнее (включая «черновик только с вложениями»).
6. Тесты (21): debounce writing→saved на 500мс, flush на `Event('pagehide')` (dispatch на window), flush на `visibilitychange` hidden и отсутствие flush при visible, flush на unmount, снятие слушателей на unmount (spy на setItem не вызывается), метаданные файлов (File → `{name,size}`, JSON ровно `{title,body,files,timestamp}`), restore с вложениями (`draft.files` = метаданные, `hasRestoredFiles=true`), legacy-restore без вложений, quota-ошибка в дебаунсе → status error без throw, quota-ошибка во flush → status error без throw, восстановление после quota, clearDraft отменяет pending и сбрасывает флаг, restoreDraft возвращает черновик и чистит буфер.
