**P2-T1. Signal Travel v2 (uKind == 0, home→board):**
Переписать ветку `if (uKind == 0) { ... }` в выразительный «сигнальный фронт»:
- Расходящийся ring от центра с хвостом частиц (несколько вложенных колец с разным затуханием)
- Radial «лучи» (SDF-подобные) от центра, мерцающие по time
- Лёгкий chromatic offset (сдвиг r/g/b на 1-2 пикселя по радиусу — через отдельные вычисления цвета и mix)
- Pulse-волна: `sin(uTime * X)` модулирует яркость
- Палитра: от steel (#5a6480) к amber (#d4882a) по мере удаления от центра
- Должно читаться как «сигнал идёт от ядра к узлу доски»
- Использовать `uAspect`, `uTime`, `uProgress`. `env` уже модулирует общую прозрачность по ходу анимации — используй его.

**P2-T2. Depth Tunnel v2 (uKind == 1, board↔thread):**
Переписать ветку `else if (uKind == 1) { ... }` в «туннель глубины»:
- Концентрические кольца, уходящие к горизонту (использовать `1.0 / (d + offset)`-подобное foreshortening, а не линейный `d`)
- «Пакеты данных» на стенках — hash-banded мерцающие яркости: `fract(sin(hash) * 43758.5)` или готовый `hash`
- Лёгкий radial blur по краям (виньетка): `1.0 - smoothstep(0.4, 1.2, d)`
- Цвет: стальной тёмный фон с amber-вспышками пакетов
- Должно читаться как «камера летит в глубину туннеля»
- `uAspect` — коррекция под экран.

**P2-T3. Archive Fracture v2 (uKind == 2, →platinum/error):**
Переписать ветку `else if (uKind == 2) { ... }` в «фрагментацию архива»:

- Edge glow: на границах ячеек — яркая amber-линия (через `smoothstep` от расстояния до границы ячейки)
- Центр «всасывается»: `smoothstep(0.0, 0.7, uProgress)` + радиальное смещение к центру
- `void(h2)` можно удалить — он был заглушкой
- Должно читаться как «архив разлетается на shard'ы»
