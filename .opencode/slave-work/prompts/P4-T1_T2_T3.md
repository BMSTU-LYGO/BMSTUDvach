**P4-T1. Reactive lighting: threadCount → emissive intensity**
В `update(dt)` для каждой board:
- `const maxThreadCount = Math.max(1, ...nodes.map(n => n.board.threadCount))` (вычислить ОДИН раз перед циклом узлов, или кэшировать в closure при `setBoards`)
- `const normalizedThreadCount = Math.min(1, n.board.threadCount / maxThreadCount)`
- `const emissiveIntensity = 0.5 + normalizedThreadCount * 1.5` (от 0.5 до 2.0)
- Применить к `n.mat.uniforms.uGlowIntensity.value = emissiveIntensity` (если не hovered).
- Сейчас в `update` уже есть логика для hover: если `isHi` (highlighted) — `uGlowIntensity.value = 2.0`. Сохранить это, но базовое значение (не hovered) — из threadCount.

**P4-T2. Inter-board connections: visual edges between nearby nodes**
В `setBoards` добавить визуальные рёбра между соседними узлами:
- После создания всех узлов — для каждого узла найти 2-3 ближайших (по расстоянию в 3D).
- Расстояние: `Math.sqrt((a.x-b.x)^2 + (a.y-b.y)^2 + (a.z-b.z)^2)`.
- Создать `Line` между узлами:
  ```ts
  const connectionGeo = new three.BufferGeometry().setFromPoints([
    new three.Vector3(a.x, a.y, a.z),
    new three.Vector3(b.x, b.y, b.z),
  ])
  const connectionMat = new three.LineBasicMaterial({
    color: STEEL,
    transparent: true,
    opacity: 0.15,
  })
  const connection = new three.Line(connectionGeo, connectionMat)
  connection.userData = { kind: 'inter-board', from: a.slug, to: b.slug }
  networkGroup.add(connection)
  ```
- Не создавать дубликаты: если A→B уже создано, не создавать B→A. Использовать `Set<string>` для отслеживания: `const key = [a.slug, b.slug].sort().join('|')`.
- Добавить в `nodeOwned` для dispose.

**P4-T3. Hover reactive lighting: highlightedBoard → усиление света**
В `update(dt)`:
- Если `snap.highlightedBoard !== null`:
  - Найти узел: `const hiNode = nodes.find(n => n.slug === snap.highlightedBoard)`
  - Если найден: `hiNode.mat.uniforms.uGlowIntensity.value = 2.5` (сильнее обычного).
  - Найти соседей (узлы, связанные с `hiNode` через inter-board edges из P4-T2):
    * Пройти по `networkGroup.children`, найти `Line` с `userData.kind === 'inter-board'` и `userData.from === hiNode.slug || userData.to === hiNode.slug`.
    * Извлечь slug соседа: `neighborSlug = userData.from === hiNode.slug ? userData.to : userData.from`.
    * Найти узел соседа: `neighborNode = nodes.find(n => n.slug === neighborSlug)`.
    * Если найден: `neighborNode.mat.uniforms.uGlowIntensity.value = 1.5` (средне).
  - Остальные узлы — оставить базовое значение из P4-T1.
- Если `snap.highlightedBoard === null` — все узлы получают базовое значение из P4-T1.
