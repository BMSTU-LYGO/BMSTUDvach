**P2-T1. Позиционирование: order → radial distance**
В `setBoards` изменить позиционирование узлов:
- Сейчас: `const radius = 6.5 + (hash(slug) % 30) * 0.1` (фиксированный радиус для всех)
- Новый вариант: `radius = baseRadius + normalizedOrder * tierSpacing`
  * `baseRadius = 5.0` (ближняя граница)
  * `tierSpacing = 4.0` (расстояние между ярусами)
  * `normalizedOrder = (board.order - minOrder) / (maxOrder - minOrder || 1)` — нормализованный order от 0 до 1
  * `minOrder = Math.min(...boards.map(b => b.order))` (вычислить один раз перед циклом)
  * `maxOrder = Math.max(...boards.map(b => b.order))` (вычислить один раз перед циклом)
- Сохранить Fibonacci lattice для углов (phi, theta):
  ```ts
  const phi = Math.acos(1 - 2 * (idx + 0.5) / boards.length)
  const theta = Math.PI * (1 + Math.sqrt(5)) * idx + (hash(slug) % 100) * 0.01
  ```
- Но `radius` теперь зависит от `order`:
  ```ts
  const radius = baseRadius + normalizedOrder * tierSpacing
  const pos = {
    x: radius * Math.sin(phi) * Math.cos(theta),
    y: radius * Math.sin(phi) * Math.sin(theta) * 0.6,
    z: radius * Math.cos(phi) * 0.8 - 2,
  }
  ```
- Узлы с низким order (более "важные") — ближе к центру, с высоким — дальше.

**P2-T2. Размер: threadCount → scale**
В `setBoards` изменить размер узлов:
- Сейчас: `baseScale: 0.8 + (hash(slug) % 30) * 0.01` (фиксированный для всех)
- Новый вариант: `baseScale = 0.5 + normalizedThreadCount * 0.8`
  * `normalizedThreadCount = clamp(board.threadCount / maxThreadCount, 0, 1)`
  * `maxThreadCount = Math.max(100, ...boards.map(b => b.threadCount))` (cap at 100 или реальный max, вычислить один раз перед циклом)
  * `clamp(x, min, max) = Math.max(min, Math.min(max, x))` (реализовать локально или использовать `Math.min/max`)
- Применить к `n.group.scale.setScalar(baseScale)` при создании узла.
- Сохранить в `BoardNode`: `baseScale` (уже есть), но вычисляется из `threadCount`.

Общие требования:
- Вычислить `minOrder`, `maxOrder`, `maxThreadCount` ОДИН раз перед циклом `boards.forEach`.
- НЕ ломать существующие методы (`pulseAt`, `sendReply`, etc.) — они работают по `slug`.
- Сохранить Fibonacci lattice для углов (phi, theta) — только `radius` меняется.
- Сохранить `hash(slug)` для theta offset — добавляет variety.
