ЧТО СДЕЛАТЬ в `frontend/src/three/network.ts`:

**P6-T1. Camera auto-orbit (home mode)**
В `update(dt)`:
- Если `snap.mode === 'home'` и НЕ `prefersReducedMotion()`:
  - `const orbitRadius = 17` (из `cameraPresets.home.z`)
  - `const orbitSpeed = 0.05` (rad/s, очень медленно)
  - `const orbitAngle = elapsed * orbitSpeed`
  - `camera.position.x = Math.cos(orbitAngle) * orbitRadius`
  - `camera.position.z = Math.sin(orbitAngle) * orbitRadius`
  - `camera.position.y = cameraPresets.home.y + Math.sin(elapsed * 0.1) * 0.5` (лёгкое покачивание по Y)
  - `camera.lookAt(0, 0, 0)` (или `lookTarget`)
  - НЕ применять обычный camera-lerp (тот, что с `smoothPointer.x * 0.9`) — auto-orbit полностью заменяет его в home mode.
- Если `snap.mode !== 'home'` — использовать обычный camera-lerp (уже есть).
- Импортировать `prefersReducedMotion` из `@/composables/useGsap` (в начале файла).

**P6-T2. Camera focus on hovered card**
В `update(dt)`:
- Если `snap.highlightedBoard !== null` и НЕ auto-orbit (т.е. mode !== 'home' или prefersReducedMotion):
  - Найти узел: `const node = nodes.find(n => n.slug === snap.highlightedBoard)`
  - Если найден:
    * `const focusStrength = 0.2` (20% смещения к узлу)
    * `camera.position.x += (node.pos.x * focusStrength - camera.position.x) * dt * 2`
    * `camera.position.y += (node.pos.y * focusStrength - camera.position.y) * dt * 2`
    * `camera.lookAt` — между ядром и узлом: `lookTarget.set(node.pos.x * 0.3, node.pos.y * 0.3, node.pos.z * 0.3)` (или оставить `lookTarget` как есть, но добавить смещение)
- Если `snap.highlightedBoard === null` — использовать обычный camera-lerp (уже есть).

**P6-T3. Reduced motion: упрощённые анимации**
В `network.ts`:
- Импортировать `prefersReducedMotion` (уже импортировано для P6-T1).
- В `update(dt)`:
  - Если `prefersReducedMotion()`:
    * Отключить auto-orbit (из P6-T1) — не применять.
    * Отключить вращение узлов: `n.group.rotation.y += 0` (вместо `dt * rotationSpeed`).
    * Упростить pulse: `pulseInterval = 10.0` (вместо 2-5с из P5-T2).
    * Упростить hover lighting: если `snap.highlightedBoard !== null` — только сам узел получает 2.5, соседи НЕ получают 1.5 (остаются на базовом значении из P4-T1).
- Уважать `prefersReducedMotion()` во всех новых анимациях (auto-orbit, focus, rotation, pulse, hover).

Общие требования:
- Импортировать `prefersReducedMotion` из `@/composables/useGsap` (один раз в начале файла).
