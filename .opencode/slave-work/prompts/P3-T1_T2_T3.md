**P3-T1. Уникальная геометрия на основе hash(slug)**
В `setBoards` для каждой board выбрать свою геометрию:
- `const geometryVariants = ['icosahedron', 'octahedron', 'dodecahedron', 'tetrahedron', 'box'] as const`
- `const variant = geometryVariants[hash(slug) % geometryVariants.length]`
- Создать геометрию в зависимости от варианта:
  - `icosahedron`: `new three.IcosahedronGeometry(0.55, high ? 2 : 1)` (уже есть)
  - `octahedron`: `new three.OctahedronGeometry(0.55, 0)`
  - `dodecahedron`: `new three.DodecahedronGeometry(0.55, 0)`
  - `tetrahedron`: `new three.TetrahedronGeometry(0.55, 0)`
  - `box`: `new three.BoxGeometry(0.8, 0.8, 0.8)`
- Все геометрии — wireframe: использовать `new three.EdgesGeometry(geo)` + `new three.LineSegments(edgeGeo, edgeMat)` (уже есть для edge wireframe).
- Применить к `nodeMesh` (основная геометрия узла).
- Сохранить в `BoardNode`: `variant` (для отладки/визуализации).

**P3-T2. Уникальный цвет на основе hash(slug)**
В `setBoards` для каждой board выбрать свой цвет:
- `const palette = [AMBER, STEEL, STEEL_LIGHT, DEEP, GLOW]` (уже определены как константы)
- `const color = palette[hash(slug) % palette.length]`
- Применить к `nodeMat.uniforms.uColor.value.setHex(color)` (уже есть, но сейчас фиксированный `STEEL`).
- Сохранить в `BoardNode`: `color` (для hover/подсветки).

**P3-T3. Уникальная скорость вращения на основе hash(slug)**
В `update(dt)` для каждой board:
- `const rotationSpeed = 0.1 + (hash(slug) % 100) * 0.005` (от 0.1 до 0.6 rad/s)
- Применить к `n.group.rotation.y += dt * rotationSpeed` (уже есть, но сейчас фиксированная скорость).
- Можно также добавить `n.group.rotation.x += dt * rotationSpeed * 0.3` (для variety).
