ЧТО СДЕЛАТЬ:
1. Создать `frontend/src/three/archive/materials.ts` — фабрики процедурных материалов
   для отдельной сцены Archive Space. Сигнатура каждой: принимает `three: ThreeModule`
   (тип `typeof import('three')`, импортируй тип ЧЕРЕЗ `import type`) и параметры,
   возвращает `THREE.ShaderMaterial`.
2. Единый контракт uniforms для ВСЕХ материалов:
   `{ uTime: {value: 0}, uFocus: {value: 0}, uDim: {value: 1} }` + опциональные
   `uColorA/uColorB/uQuality`. Экспортировать `archiveUniforms(extra?)`, чтобы сцена
   могла двигать общие униформы одним place.
3. Фабрики:
   - `fragmentMaterial(three, opts)` — «бумажная пластинка фрагмента»: fresnel-кромка
     (pow от dot(normal, viewDir)), зерно из дешёвого hash-шума по UV/позиции (тёплый
     бумажный тон), accent-подсветка при `uFocus` (glow строго в кромке), прозрачность
     зависит от `uDim`; `side: three.DoubleSide`, `depthWrite: false`.
   - `ringMaterial(three, opts)` — орбита колец: линии с «дыханием» яркости по `uTime`
     (синус с фазой) и лёгким бегущим шумом, базовый цвет STEEL/paper-ink, при `uFocus`
     тёплый amber. Работает и на `LineSegments` (шейдер не требует нормалей — используй
     `position`/`uv`-безопасный код).
   - `vaultMaterial(three, opts)` — ядро-хранилище: медленный moving fresnel + внутренний
     amber-пульс; при `uDim`<0.5 уходит в почти невидимый.
   - `dustMaterial(three, opts)` — `PointsMaterial`-заменитель на шейдере: additive,
     мерцание по `uTime` с индивидуальной фазой из атрибута `aSeed` (документировать,
     что сцена обязана задать `aSeed`).
   - `emptyHaloMaterial(three, opts)` — мягкий гало для empty-state (пустые кольца
     «дышат»), только additive, никаких резких вспышек.
4. Quality: `high` — полный шум + antialias-friendly параметры; `low` — упрощённая
   версия (меньше octaves/без второго слоя шума) через параметр `quality: 'high'|'low'`.
   Никаких `#define`-веток, ломающих компиляцию в headless-тестах.
5. Все GLSL-строки — в константах вида `const fragmentVert = /* glsl */ \`...\`` (как в
   network.ts), с `gl_FragColor`. Не использовать функции, отсутствующие в GLSL ES 1.00
   (WebGL1-safe: без `texture()`, без `invert()`; `fract/pow/smoothstep/dot/normalize` — можно).
6. Экспортировать `disposeArchiveMaterials(list)` — хелпер `material.dispose()`.
7. Создать `frontend/src/three/archive/__tests__/materials.spec.ts` — юнит-тесты:
   фабрики возвращают объект с `.dispose`/`.uniforms` с `uTime/uFocus/uDim`; все
   фрагментные шейдеры содержат `gl_FragColor`; uniforms у всех фабрик содержат нужные
   keys; `quality: 'low'` отличается от `high` (например по флагу/числу octaves в
   uniforms или по `defines`); `dispose` вызывается без ошибок. THREE можно собрать
   моком (не тянуть WebGL renderer), как принято в `src/three/__tests__/network.spec.ts`
   — посмотри, как это сделано там, и повтори подход.
