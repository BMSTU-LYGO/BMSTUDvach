ЧТО СДЕЛАТЬ:
1. `frontend/src/views/PlatinumView.vue` — клавиатура как основной способ навигации по архиву (DOM-список остаётся источником правды, 3D лишь следует):
   - строки-списка должны быть достижимы клавишами: каждая строка — фокусируемый элемент (`tabindex`/`button`-семантика по текущей разметке), `Enter` открывает историю, `ArrowUp/ArrowDown` (и `Home`/`End`) двигают выделение по строкам;
   - перемещение по клавиатуре двигает `focusStory(id)` + `emitSceneEvent({ type: 'archive-focus', target: id })` — 3D-сцена реагирует тем же, что и при наведении мышью;
   - `aria-live="polite"`-область объявляет «фрагмент N · <title>» (или «N из M») при смене выделения — без спама (объявлять только при клавиатурной/ручной смене фокуса, не на каждый mousemove);
   - переключатель «3D / только текст» (визуально аккуратный, в стиле существующих контролов проекта): `aria-pressed`, состояние сохраняется в `localStorage` (проверь существующий паттерн `src/composables/useLocalData.ts`), по умолчанию — 3D включён; при выключенном 3D — канвас не рендерится/скрывается, DOM-слой полностью функционален;
   - никаких focus-ловушек (focus trap), фокус должен свободно уходить со страницы; видимый focus-ring не хуже текущего (контраст ≥ 4.5:1 для подписей);
   - не сломать существующие `data-testid` (`fragment-row`, `platinum-empty`) и текущую типографику/measure.
2. `frontend/src/components/three/ArchiveSpaceCanvas.vue` — синхронизация с клавиатурным фокусом и переключателем текст-режима:
   - при `focusStory` из списка — сцена уже реагирует (проверь, что `archive.focus` не вызывает «прыжок» камеры на каждый hover — правило «камера летит только при открытии» должно сохраниться);
   - добавить поддержку режима «только текст»: при выключенном 3D — сцена/канвас не активны (экономия контекста WebGL, `MAX_ACTIVE_CONTEXTS` не трогать);

   - при `prefersReducedMotion()` никаких «прыжков» и лишних анимаций.
