ЧТО СДЕЛАТЬ:
1. Создать `frontend/src/three/archive/layout.ts` — МОДУЛЬ БЕЗ THREE ОБЪЕКТОВ: только
   чистые функции и числа (чтобы тестировать без WebGL). Никаких импортов из 'three'.
2. Типы:
   - `ArchiveRing { index: number; radius: number; stories: number[] }`
   - `FragmentPlacement { id: number; ringIndex: number; angle: number; radius: number;
     x: number; y: number; z: number; tilt: number; scale: number; seed: number }`
   - `LayoutInputStory { id: number; sourceType?: string; publishedAt?: string | null; year?: number | null }`
     (совместимый с `PlatinumStory` минимальный контракт; НЕ импортируй vue/pinia).
   - `LayoutOptions { rings?: number[]; maxFragments?: number; shellRadius?: number; tierSpacing?: number }`
3. Экспортировать API:
   - `hashId(input: string | number): number` — стабильный хеш (та же схема, что `hash()` в network.ts).
   - `ringsFor(stories: LayoutInputStory[], opts?: LayoutOptions): ArchiveRing[]` —
     кольца по «эпохам»: год публикации (`publishedAt` → `new Date(...).getFullYear()`,
     отсутствующая/невалидная дата → самый внутренний круг «неопубликованные»), истории
     одного года сидят на одном кольце; кольца сортируются по году; radius =
     shellRadius + tier index * tierSpacing (deфолты: shellRadius 3.0, tierSpacing 1.8 —
     как текущие radii [3.0, 4.8, 6.6]).
   - `placeFragments(stories, opts?): FragmentPlacement[]` — детерминированная расстановка:
     angle = золотой угол (2.39996) * индекс внутри кольца + сдвиг от hashId(id) (чтобы
     не было «веера» одинаковых углов), y-высота = амплитуда от hash (±0.35), tilt от
     `sourceType` (маппинг неизвестных типов → 0), scale 0.8..1.35 от hash; кап
     `maxFragments` (дефолт 60) — лишние отбрасываются СТАБИЛЬНО (по id, не по порядку).
   - `fragmentById(placements, id): FragmentPlacement | undefined`
   - `layoutSignature(stories): string` — дешёвая подпись набора (`ids:joined`), чтобы
     Vue-watch понимал, что набор реально изменился.
4. Права на крайние случаи: 0 историй → `[]` и `ringsFor` → [] без NaN; 1 история;
   все даты одинаковые; даты битые (`''`, `'garbage'`, `null`); дубли id (последний выигрывает);
   `maxFragments <= 0` → []. Никаких `Infinity`/`NaN` в выходе.
5. Создать `frontend/src/three/archive/__tests__/layout.spec.ts` — таблицные юнит-тесты
   (vitest, как в `src/three/__tests__/`): детерминизм (одинаковый вход → одинаковый выход,
   порядок входа не влияет на позицию данного id), кольца по годам, fallback-кольцо,
   кап, отсутствие NaN, `layoutSignature` меняется только при смене набора.
