     * `pointermove` → NDC из `clientX/clientY` относительно БУНДА канваса

       `space.setPointer(x, y)`; затем `const hovered = space.pointerStoryId()`;
       если `hovered !== sceneState.focusedStory` → `focusStory(hovered)` +
       `emitSceneEvent({ type: 'archive-focus', target: hovered })`;

       владеет фокусом (контракт P3-T1);
     * `click` на канвасе → если `pointerStoryId()` есть → `selectStory(id)` +
       `emitSceneEvent({ type: 'archive-open', target: id })` +
       `space.travelToFocus()` (кинематографичный подлёт перед переходом);
     * drag: `pointerdown` → захват (`setPointerCapture`), `pointermove` с зажатой

       `pointerup`/`pointercancel` → отпускание; клик ≠ drag (порог ~4px, иначе не эмитим
       `archive-open`);
     * `wheel` НЕ перехватывать (страница должна скроллиться), слушатели passive;
     * всё снять в `dispose`/`onUnmounted`.
