**P3-T1. Morph-инфраструктура в update(dt).**
У тебя уже есть `morph = { target, duration, elapsed, active }` из P1-T3. Теперь используй его для topology morphing:
- Создать `morphPresence` объект: `{ network: 1, archive: 0, lost: 0 }` (как текущий `presence`, но управляемый morph'ом)
- Когда `morph.active === true`:
  * `morphElapsed += dt`
  * `t = Math.min(1, morphElapsed / morph.duration)`
  * `easedT = easeInOutCubic(t)`
  * В зависимости от `morph.target`:
    - если target === 'platinum': `morphPresence.network = 1 - easedT`, `morphPresence.archive = easedT`, `morphPresence.lost = 0`
    - если target === 'error': `morphPresence.network = 1 - easedT`, `morphPresence.archive = 0`, `morphPresence.lost = easedT`
    - если target === 'home' или 'board': `morphPresence.network = easedT`, `morphPresence.archive = (morphPresence.archive > 0.5) ? 1 - easedT : 0`, `morphPresence.lost = 0`
    - если target === 'thread': `morphPresence.network = 1` (thread — calm mode, не уходит)
  * Во время morph — `presence.network/archive/lost` должны lerp К `morphPresence.*` быстрее обычного (например, `ease * 4` вместо `ease`)
- Когда `morph.active === false` — `presence.*` ведёт себя как раньше (штатный lerp к targets из snap.mode)
- Важно: НЕ ломать существующий `presence`-код, а добавить слой поверх. Если morph не идёт — поведение идентично текущему.
- Визуальный эффект: при переходе home→platinum board nodes не просто исчезают (visibility toggle), а плавно уходят в `presence.network → 0`, а archive rings появляются через `presence.archive → 1`.

**Дополнительно к P3-T1 — «топологическая трансформация»:**
- Когда `morph.target === 'platinum'` и `morph.active`:
  * board nodes должны не просто fade'иться, а «сворачиваться» — можно добавить в node-update `n.group.scale.setScalar(n.scale * (1 - easedT * 0.9))` когда morph идёт к platinum (nodes уходят в точку)
  * archive rings (ringMeshes) должны появляться с scale от 0 до 1 — добавить `ringMesh.mesh.scale.setScalar(easedT)` когда morph к platinum
- Когда `morph.target === 'error'`:
  * lostNode должен материализоваться: `lostMat.opacity = ... * easedT` (вместо скачка visible)
- Когда `morph.target === 'home'/'board'`:
  * если пришёл из platinum — обратный morph (archive уходит, network возвращается)

**P3-T2. Shared-element: board slug → node.**
Добавить в `NetworkController` новый метод:
```ts
anchorSharedElement(slug: string | null): void
```
- Если slug передан и это валидный board node: камера во время `traveling` должна смотреть не на `(0, travelTarget.lookY, 0)`, а на позицию этого узла (или между узлом и ядром). В `travelTo` добавить опциональный `sharedSlug?: string` (не обязательно — можно передавать через отдельный метод).
- Проще: в `update(dt)`, если `traveling && sharedAnchor !== null`:
  * `node = nodes.find(n => n.slug === sharedAnchor)`
  * если node найден: `lookTarget = (node.pos.x * 0.6, node.pos.y * 0.6, node.pos.z * 0.6)` (как в текущем board-mode code)
  * узел получает временный `sharedHighlight = 1` (дополнительный флаг, который делает узел ещё ярче, чем обычный `highlightedBoard`): `n.mat.uniforms.uGlowIntensity.value = 2.8` вместо 2.0, `n.mat.uniforms.uColor.value.setHex(AMBER_BRIGHT)`
- Когда travel заканчивается — `sharedAnchor` сбрасывается в null.

Добавить в интерфейс:

**P3-T3. Shared-element: thread → packet.**
Добавить в `NetworkController`:
```ts
launchEnvoyPacket(fromSlug: string): void
```
- Находит узел by slug, создаёт «усиленный» пакет (из `packetPool`):
  * `p.curve = new QuadraticBezierCurve3(node.pos, midPoint, core)` где `midPoint = (node.pos.x*0.4, node.pos.y*0.4 + 3, 3)` (как в `sendReply`)
  * `p.mat.uniforms.uColor.value.setHex(AMBER_BRIGHT)`, `p.mat.uniforms.uOpacity.value = 1`
  * `p.active = true`, `p.t = 0`
  * `cameraKick = Math.min(0.5, cameraKick + 0.22)`
- По сути — это переиспользование существующего `sendReply` но с конкретным source node (а не случайным). Можно вызвать `sendReply()` и всё, но если хотим именно от конкретного узла — делаем отдельный метод.
- Вызывается из director'а, когда сценарий имеет `sharedElement === 'thread-packet-envoy'` и `from === 'board'`.
