**P5-T2. Ambient pulse rate: threadCount → pulse frequency**
В `frontend/src/three/network.ts`:
- В `setBoards` для каждого узла инициализировать `pulseTimer = 0` (добавить в `BoardNode`: `pulseTimer: number`).
- В `update(dt)` для каждого узла:
  ```ts
  const maxThreadCount = ... (уже кэширован из P4-T1)
  const normalizedThreadCount = Math.min(1, n.board.threadCount / maxThreadCount)
  const pulseInterval = 5.0 - normalizedThreadCount * 3.0 // от 5с до 2с
  n.pulseTimer += dt
  if (n.pulseTimer >= pulseInterval) {
    pulseAt(n.slug) // автоматический pulse для активных boards
    n.pulseTimer = 0
  }
  ```
- Это создаст ambient pulse — узлы с большим threadCount пульсируют чаще.
