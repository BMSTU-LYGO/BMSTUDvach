# Slave Work Plan — Переработка WebGL route transitions в цельную пространственную навигацию

- **Статус:** complete
- **Модель субагентов:** `opencode-go/step-5-preview-free`
- **Запуск:** 2026-10-14
- **Engine:** cli, parallel: 6, waves: 1
- **Смысловой якорь:** переходы — это не маски на странице, а движение единой камеры по «инженерной сети BMSTU». Разные маршруты = разные сценарии путешествия, но общий художественный язык: signal front, depth rings, fracture shards, amber/steel палитра, breathing core.

## Контекст для субагентов

- **Стек:** Vue 3 + TypeScript + Vite + Three.js (0.186) + GSAP.
- **Структура 3D:**
  - `frontend/src/three/network.ts` — `buildNetwork(...)`: единая сцена (home/board/thread/platinum/error) с presence-lerпанными группами `networkGroup`, `archiveGroup`, `lostGroup`, `coreGroup`.
  - `frontend/src/three/warps.ts` — оверлей-shader (`warpKindFor`, `makeWarpMaterial`, kinds: `signal`/`tunnel`/`fracture`/`soft`). Регистрируется `registerWarpPlayer` и проигрывается из `WarpCanvas.vue`.
  - `frontend/src/three/sceneState.ts` — реактивный стейт режимов и событий (`pulse`, `reply`, `rescue`, `thread-launch`, …).
  - `frontend/src/components/three/NetworkCanvas.vue` — постоянный WebGL-canvas; `WarpCanvas.vue` — оверлей.
  - `frontend/src/components/three/NetworkCore.vue` — hero-ядро на Home (отдельный canvas, не трогать без нужды).
  - `frontend/src/layouts/DefaultLayout.vue` — связывает `useRouteScene` с `playWarp(warpKindFor(from,to))`.
  - `frontend/src/composables/useRouteScene.ts` — биндинг route meta → `setSceneMode`.
- **Ключевые каталоги:** `frontend/src/three/`, `frontend/src/components/three/`, `frontend/src/views/`, `frontend/src/layouts/`, `frontend/src/composables/`.
- **Команды верификации (внутри frontend-контейнера или хоста если node_modules есть):**
  - `cd frontend && npm run verify:3d` — structural guard (НЕ ЛОМАТЬ: обязательные строки/функции в `network.ts`, `warps.ts`, `WarpCanvas.vue`, `sceneState.ts`, `router/index.ts`, `useRouteScene.ts`, `BoardCard3D.vue`, `PlatinumView.vue`, `ThreadView.vue`).
  - `cd frontend && npm run lint`
  - `cd frontend && npm run build` (vue-tsc + vite build)
  - `cd frontend && npm run test`
- **Бюджет WebGL:** максимум 2 контекста — `NetworkCanvas` + `WarpCanvas`. Не добавлять третий.
- **Особенности и грабли:**
  - `verify:3d` требует в `warps.ts` обязательные слова: `gl_FragColor`, `'signal'`, `'tunnel'`, `'fracture'`, `makeWarpMaterial`, `registerWarpPlayer`. В `network.ts` — `buildNetwork`, `setBoards`, `pulseAt`, `sendReply`, `TorusGeometry`, `setStoryCount`, `lostNode`, `Raycaster`. Не переименовывать.
  - `WarpCanvas` — полноэкранный quad поверх страницы; z-index `var(--z-warp)`. Длительность `DURATION=0.65`.
  - `useThreeScene` контролирует качество (`high`/`low`/`off`) и pause на `visibilitychange`/`IntersectionObserver`.
  - `prefers-reduced-motion` уже обрабатывается в `WarpCanvas` (пропуск проигрывания).
  - `sceneState` реактивный — `watch` в `NetworkCanvas` синхронизирует `boards`/`storyCount`.
