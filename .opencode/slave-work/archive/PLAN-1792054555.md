## Контекст для субагентов

- **Стек:** Vue 3 + TypeScript + Vite + Three.js (0.186) + GSAP.
- **Структура 3D:**
  - `frontend/src/three/network.ts` — `buildNetwork(...)`: единая сцена (home/board/thread/platinum/error). Включает: `coreGroup` (центральный backbone), `networkGroup` (board nodes + edges), `archiveGroup` (platinum), `lostGroup` (404), pulses, packets.
  - `frontend/src/three/sceneState.ts` — `sceneState.mode`, `sceneState.boardSlug`, `sceneState.highlightedBoard`, `sceneState.boards: string[]`, `sceneState.storyCount`.
  - `frontend/src/three/warps.ts` — route transition warp overlay (не трогаем).
  - `frontend/src/three/transitionDirector.ts`, `frontend/src/three/scenarios.ts` — transition engine (не трогаем в этой волне).
  - `frontend/src/components/three/NetworkCanvas.vue` — постоянный WebGL-canvas; `WarpCanvas.vue` — warp overlay.
  - `frontend/src/components/three/NetworkCore.vue` — hero-ядро на Home (отдельный canvas, не трогаем).
  - `frontend/src/components/ui/BoardCard3D.vue` — HTML-карточка доски. Hover → `highlightBoard(slug)`, клик → `emitSceneEvent({type:'pulse', target:slug})`.
  - `frontend/src/views/HomeView.vue` — список досок (`.boards-grid` с `<BoardCard3D v-for>`).
- **Ключевые каталоги:** `frontend/src/three/`, `frontend/src/components/three/`, `frontend/src/components/ui/`, `frontend/src/views/`, `frontend/src/composables/`.
- **Тип `Board`** (frontend/src/types/index.ts): `id, slug, name, description, rules?, is_active, order, thread_count, created_at, updated_at`. Для визуализации используем: `slug` (hash → уникальный образ), `thread_count` (→ размер/яркость), `order` (→ позиция/ярус), `name`/`description` (→ tooltip/label).
- **Команды верификации:**
  - `cd frontend && npm run verify:3d` — structural guard (46 проверок). Обязательные строки в `network.ts`: `buildNetwork`, `setBoards`, `pulseAt`, `sendReply`, `TorusGeometry`, `setStoryCount`, `lostNode`, `Raycaster`. В `sceneState.ts`: `home`, `board`, `thread`, `platinum`, `error`, `onSceneEvent`, `emitSceneEvent`. В `BoardCard3D.vue`: `highlightBoard`, `emitSceneEvent({ type: 'pulse'`.
  - `cd frontend && npm run lint`
  - `cd frontend && npm run build` (vue-tsc + vite build)
  - `cd frontend && npm run test`
- **Бюджет WebGL:** максимум 2 контекста (`NetworkCanvas` + `WarpCanvas`). Не добавлять третий.
- **Особенности и грабли:**
  - `NetworkCanvas` рендерится на ВСЕХ маршрутах. Constellation map — это расширение режима `home` (и опционально `board`), но НЕ должно ломать	thread/platinum/error режимы.
  - `setBoards(slugs)` сейчас принимает `string[]`. Для визуализации нужно больше данных (thread_count и т.д.) — расширить до `BoardSummary[]` или `{ slug, threadCount, order }[]`. Но `syncBoards` в sceneState тоже `string[]`. Решение: добавить новый метод `setBoardsDetailed(boards: BoardSummary[])` или расширить `setBoards` принимать объекты (breaking change — нужно обновить всех вызывающих). Выбери расширение с обратной совместимостью: `setBoards(input: string[] | BoardSummary[])` — если массив строк,	thread_count = 0.
  - `highlightBoard(slug)` уже работает в обоих направлениях: HTML card → 3D node. Добавить обратное: raycast на 3D node → highlight HTML card (через data-attribute или ref).
  - `prefers-reduced-motion` — уважать: никаких auto-orbit, упростить pulse-анимации.
  - `quality=high|low|off` — уже есть. На `low` — упрощённые шейдеры, меньше деталей.
