# Slave Work Plan — ThreadView redesign + Reply Graph

- **Статус:** in progress
- **Модель субагентов:** `opencode-go/step-5-preview-free`
- **Запуск:** 2026-10-15 (волна 3)
- **Engine:** cli, parallel: 6, waves: 1

## Контекст для субагентов

- **Стек:** Vue 3 + TypeScript + Vite + Three.js (0.186) + GSAP.
- **Структура ThreadView:**
  - `frontend/src/views/ThreadView.vue` (~1053 строк): шапка (breadcrumb, title, watch, search), posts container с `<article class="post-item">` для каждого поста (GenerativeAvatar + header + PostBody + backlinks + ReportProbe), SignalDock, ContextFiber, PostPreview.
  - `frontend/src/components/thread/PostBody.vue` (~456 строк): signature (author + tripcode), body с paragraph/quote/gap блоками, post-links (`>>123`) с hover preview, attachments (image/file), lightbox.
  - `frontend/src/components/thread/PostPreview.vue` (~115 строк): desktop hover preview для `>>123` ссылок.
  - `frontend/src/composables/usePostLinks.ts`: `parsePostLinks`, `collectBacklinks` (post id → ids of posts that link to it).
- **Тип `Post`** (frontend/src/types/index.ts): `id, thread, body, is_op, sage, created_at, updated_at, author, tripcode, attachments`.
- **Команды верификации:**
  - `cd frontend && npm run verify:3d` — structural guard (46 проверок). Для ThreadView обязательна строка `emitSceneEvent({ type: 'reply' })`.
  - `cd frontend && npm run lint`
  - `cd frontend && npm run build` (vue-tsc + vite build)
  - `cd frontend && npm run test`
- **Художественный язык:** engineering network, paper/ink палитра (#F2EDE0 paper, #1C1A14 ink, #2F4F4E accent, #d4882a amber), JetBrains Mono/Cormorant Garamond/Inter шрифты. НЕ generic cyberpunk, НЕ hacker terminal.
- **Приоритет:** удобное чтение > выразительность. Reply Graph — дополнение, не замена читаемости.
- **Особенности и грабли:**
  - ThreadView уже имеет: search, watch, backlinks, hover preview, quote insertion, report probe, sage, lightbox, reading position, scroll reveal.
  - НЕ ломать существующую функциональность: quote insertion, report, search, watch, lightbox, reading position.
  - `emitSceneEvent({ type: 'reply' })` обязательно присутствует в ThreadView (verify:3d).
  - Mobile-first: все изменения должны работать на mobile (320px+).
  - `prefers-reduced-motion` — уважать.

### Фаза 2 — Reply Graph

- [ ] **P2-T1. Reply Graph data structure** — создать composable `useReplyGraph.ts`:
  - На основе `collectBacklinks` (уже есть) построить граф: для каждого поста — `replies: number[]` (посты, на которые ссылается этот), `quotedBy: number[]` (посты, которые ссылаются на этот — уже есть в backlinks).
  - Экспортировать `useReplyGraph(posts: Post[])` → `{ getReplies(postId), getQuotedBy(postId), getChain(postId): number[] }` (цепочка: пост + все posts, которые на него ссылаются, рекурсивно).
  - Файлы: `frontend/src/composables/useReplyGraph.ts`
  - Приёмка: composable работает, `getChain` возвращает цепочку. `verify:3d` проходит.
  - deps: none | size: S

- [ ] **P2-T2. Reply Graph sidebar: визуализация связей** — создать компонент `ReplyGraphSidebar.vue`:

  - Визуально: tree-like structure с линиями связей (CSS, не SVG для простоты).
  - Клик на post в sidebar → scroll к этому посту.
  - Файлы: `frontend/src/components/thread/ReplyGraphSidebar.vue`, `frontend/src/views/ThreadView.vue` (добавить sidebar)
  - Приёмка: sidebar виден на desktop, показывает связи, клик скроллит. `verify:3d` проходит.
  - deps: P2-T1 | size: M

- [ ] **P2-T3. Reply Graph inline: подсветка цепочек** — в ThreadView.vue добавить inline-подсветку:
